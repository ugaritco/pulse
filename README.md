## Introduction

Ugarit Pulse is a real-time application performance monitoring tool and dashboard for your Ugarit application.

## Official Documentation

Documentation for Pulse can be found on the [Ugarit website](https://ugarit.com/docs/pulse).

## Contributing

Thank you for considering contributing to Pulse! The contribution guide can be found in the [Ugarit documentation](https://ugarit.com/docs/contributions).

## Code of Conduct

In order to ensure that the Ugarit community is welcoming to all, please review and abide by the [Code of Conduct](https://ugarit.com/docs/contributions#code-of-conduct).

## Security Vulnerabilities

Please review [our security policy](https://github.com/ugarit/pulse/security/policy) on how to report security vulnerabilities.
